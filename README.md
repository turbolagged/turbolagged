### Projects

**[ng-bash-deploy](https://github.com/turbolagged/ng-bash-deploy)**
A Bash script that builds an Angular app and deploys it to a remote server over SSH. It reads a config file, so it works across projects and servers. I wrote it when our team moved to a self-hosted GitLab and we needed another way to deploy. It's used in production.

**[Vaercast](https://github.com/turbolagged/Vaercast)** · [Live demo](https://vaercast.vercel.app/)
A weather app built with React and the Open-Meteo API. Search for a place and see the current temperature, feels-like, conditions, wind, humidity, UV index and pressure.
