### About me

I'm a frontend-focused software engineer with 7 years of experience building production web apps in Angular and TypeScript. I've been with Angular since the AngularJS days in 2018 and have led migrations from AngularJS to Angular and from v14 to v18 and v20, with zero regressions.

I've built authentication flows, bKash/Nagad payment integrations, role-based dashboards, and real-time notifications. I've also acted as team lead, running standups, reviewing merge requests, and mentoring junior engineers.

I'm comfortable in Linux and I built my own deployment script for shipping Angular builds over SSH. Beyond Angular, I have hands-on experience with React see [Vaercast](https://vaercast.vercel.app) and some working experience with Node.js/Express, SQL and MongoDB.

**Ask me about:** Angular, TypeScript, RxJS, upgrading legacy apps
