### 📌 Featured Projects

**[Angular Deployment Automation](https://github.com/turbolagged/ng-bash-deploy)**
A configurable Bash script that automates deploying Angular apps to a remote server via SSH. Built after our team migrated to a self-hosted GitLab instance and needed to adapt the CI/CD pipeline — the script handles building the project, transferring the compiled output, and deploying it to the target directory, driven by a simple config file (SSH credentials, paths, remote target) so it's reusable across projects/servers. Used in production to replace manual deployment steps after the migration.
